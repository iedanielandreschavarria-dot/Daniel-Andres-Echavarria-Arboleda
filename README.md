## 👨‍💻 Sobre mí

Soy aprendiz de **Análisis y Desarrollo de Software ADSO** y desarrollador de software junior en formación.

Tengo conocimientos en desarrollo web con **JavaScript**, programación orientada a objetos con **Python**, construcción de APIs REST, bases de datos relacionales y desarrollo de videojuegos con **Unity y C#**.

Me interesa crear soluciones útiles, comprender cómo funcionan los sistemas y mejorar continuamente mis habilidades. También exploro herramientas de inteligencia artificial para apoyar el desarrollo, el prototipado y la optimización de activos digitales.

Actualmente busco una oportunidad para realizar mi **etapa productiva mediante un contrato de aprendizaje**, aportar mis conocimientos y seguir creciendo dentro de un equipo de desarrollo.
